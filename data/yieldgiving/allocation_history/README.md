# Published allocation vectors

These immutable snapshots preserve the allocation vectors exported before the
November 2026 Form 990 identity corrections. Copied byte-for-byte from
`web/allocation_v10.json` and `web/allocation_v11.json` at repository commit
[`19a90d4`](https://github.com/MaxGhenis/mackenzie-scott-qaly/tree/19a90d49e794d6d5658d6bd479829b3cb32b3fc6/web).

`msqaly.exportversions` copies these historical vectors and derives v1.2 from
current inputs. Regenerating current inputs must not rewrite published history.
